# 🚚 Food Trucks App

## 📌 Project Overview

The Food Trucks App is a full-stack web application designed to manage and interact with food truck data through a responsive user interface and a structured backend API.

This project demonstrates the ability to design and build a complete system from frontend to backend, including data handling, API architecture, and user interaction. The application focuses on delivering a clean UI while supporting dynamic data operations through a RESTful backend.

---

## 🚀 Features

- 📋 View all food trucks
- 🌱 Filter vegan food trucks
- 💲 Filter by price level
- ⭐ View top-rated food trucks
- 📊 Sort food trucks by rating or price
- 📍 Update food truck locations
- 🔢 Display total number of food trucks

## 🔌 API Overview

The backend is built using RESTful principles and exposes endpoints for retrieving, filtering, sorting, and updating food truck data.

Example endpoints:

- `GET /get-all-food-trucks`
- `GET /get-vegan-food-trucks`
- `GET /get-food-trucks-by-price/:price`
- `GET /get-top-rated-food-trucks`
- `GET /get-food-trucks-sorted-by-rating`
- `GET /get-food-trucks-sorted-by-price`
- `GET /get-food-trucks-count`
- `POST /add-one-food-truck`
- `POST /update-food-truck-location`
